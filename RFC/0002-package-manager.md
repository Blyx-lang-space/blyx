# RFC 0002: Blyx Package Manager (`blyxpkg`) Manifest & Lockfile Format

- Feature Name: `blyxpkg_manifest`
- Start Date: 2026-07-31
- Status: Implemented

## Summary
Specifies the structure of `Blyx.toml` manifests and `Blyx.lock` dependency lockfiles for building, testing, and publishing packages to `https://blyx-lang.space/registry`.
