## Installing Blyx via `blyxup`

The recommended method to install the Blyx compiler (`blyxc`), package manager (`blyxpkg`), and toolchain is using `blyxup`:

```bash
# Install stable toolchain channel
blyxup install stable

# Verify installation
blyxc --version
blyxpkg --version
```
