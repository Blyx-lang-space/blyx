# Blyx Request for Comments (RFC) Process (Phase 11 - Step 5)

Official Domain: https://blyx-lang.space

---

## 1. What is an RFC?

The "RFC" (Request for Comments) process is how major new features, syntax modifications, or standard library additions are proposed and reviewed for the Blyx Programming Language.

## 2. The RFC Lifecycle

```
  Submitting Proposal
          │
          ▼
   ┌─────────────┐
   │ Draft RFC   │ Open PR in `blyx-lang/rfcs` repository
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐
   │ Community   │ Public discussion and refinement period
   │ Review      │
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐
   │ Final Comment│ 10-day final comment period before merging
   │ Period (FCP)│
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐
   │ Acceptance  │ RFC merged & implementation tracked in compiler roadmap
   └─────────────┘
```
