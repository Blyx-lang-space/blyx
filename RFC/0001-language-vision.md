# RFC 0001: Blyx Language Vision & Core Principles

- Feature Name: `blyx_vision`
- Start Date: 2026-07-31
- Status: Accepted

## Summary
Defines the core principles governing the Blyx Programming Language design: memory safety without garbage collection, native static tensor primitives (`tensor<T, D1, D2>`), actor concurrency model, inline GPU execution blocks (`gpu { ... }`), and AI-first systems performance.
