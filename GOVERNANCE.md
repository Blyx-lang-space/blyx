# Blyx Open Source Governance Model

Official Domain: https://blyx-lang.space

---

## Governance Teams

1. **Core Team**: Overall project direction, release authorization, and security disclosures.
2. **Compiler Team**: Maintenance of `blyxc`, `compiler/blyx_bir`, and LLVM code generation.
3. **Tools & Ecosystem Team**: Maintenance of `blyxpkg`, `blyxfmt`, `blyx-analyzer`, `blyxdoc`, and `blyxup`.
4. **Libs Team**: Maintenance of `library/blyx` runtime and `library/blyx-std` standard library.
