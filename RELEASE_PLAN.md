# Blyx Alpha v0.1 Release Plan

Official Domain: https://blyx-lang.space

---

## 1. Release Targets
- **Core Binary**: `blyxc`
- **Package Manager**: `blyxpkg`
- **Formatter**: `blyxfmt`
- **Language Server**: `blyx-analyzer`
- **Editor Integration**: VS Code extension (`editors/code/`)

## 2. Validation Criteria
- All 11 code examples in `examples/` compile and execute.
- UI test suite in `tests/ui/blyx/` passes cleanly.
- Web portal (`https://blyx-lang.space`) and playground (`play.blyx-lang.space`) live.
