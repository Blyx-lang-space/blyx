# Blyx v1.0.0-rc.1 Release Notes & Checksum Guide (Phase 13 - Step 8)

Official Domain: https://blyx-lang.space
Repository: https://github.com/Blyx-lang-space/blyx

We are proud to announce the first Release Candidate: **Blyx v1.0.0-rc.1**!

---

## 1. Release Highlights

- **Blyx Intermediate Representation (BIR)**: Production-grade SSA instruction set and CFG compiler pass engine in `compiler/blyx_bir`.
- **LLVM IR Emission Pipeline**: Complete `--emit llvm-ir` and `-o <exec>` target code generator.
- **Ecosystem Toolchain Suite**: `blyxpkg`, `blyxfmt`, `blyx-analyzer` LSP, `blyxdoc`, `blyxup`, `blyxdbg`, `blyxprof`.
- **Runtime & Standard Library**: Core runtime `library/blyx` and standard library `library/blyx-std`.
